建议独立开设 Studio，以照片为主、文字为辅。沿用网站的暖白底色与字体，用自然的空间和人物关系呈现艺术家的日常；About 保留一本书式的阅读体验，在书架后增加一张 Studio 入口照片。

THE ARTIST & THE WORK

由空间进入作品：两张人物与绘画的合影错落排布，左侧 Mickey 图连接首页作品，右侧地图形作品展开不同面貌。人物靠近画面底部，使用完整图片，不做横幅式裁切。

建议的落地方式

  1. 入口：新增独立 /studio 页面，导航放在 About 之前；About 书架后放空间照与「Visit the studio」入口。首页继续以作品开场。
  2. 电脑端：大幅空间照、错落双图、单幅收尾；图片可点击查看完整大图，支持键盘关闭与前后翻阅。
  3. 手机端：四张照片按相同顺序纵向排列；保持原比例，图注紧随照片，不增加占满屏幕的开场动画。
  4. 以后更新：Studio 顶部保留这组空间照片，下方新增 Studio notes。WIP 与短文共用一份按日期排列的列表；有内容后再出现筛选与入口，不预放空栏目。
  5. 每篇记录：标题、日期、封面、正文或简短说明、附图，可关联已完成作品。作品完成后，正式照片进入 Works，过程记录继续保留。

这四张照片主要呈现人物与作品，并非绘画过程特写。暂不标注未知的拍摄年份、城市或过程说明；真正的 WIP 照片到位后再补充。此提案没有新增网站导航或正式 Studio 页面。
