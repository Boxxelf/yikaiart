# 作品更新文件放在这里

1. 打开 https://www.yikaistudio.com/works-editor
2. 选择「新增作品」或「修改已有作品」，填写资料并下载更新文件。
3. 在本文件夹点 **Add file → Upload files**，上传刚刚下载的 `.json` 文件。
4. 点 **Commit changes**，选择 **Commit directly to the main branch** 并确认。
5. 等待网站自动发布后，在 https://www.yikaistudio.com/works 核对。

每次处理一件作品。图片已经包含在文件里，不需要另外上传。
保持下载时的完整文件名；修改已有作品时，同名文件会替换之前的更新。
若电脑添加了 `(1)`，上传前请删去这个后缀。请使用有写入权限的 GitHub 账号。
不要删除本文件夹内已有的更新文件：删除可能使作品消失或恢复原来的资料。

完整操作手册：[长辈版操作说明](../../docs/works-upload/操作说明.md)。
